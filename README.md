# FlowForge

**FlowForge** is a visual workflow builder designed to help users create and understand workflows through an interactive interface.

## Features

- Visual workflow editor
- Interactive workflow blocks and connections
- Dark-themed interface
- React-based application powered by Vite
- Web deployment through GitHub Pages
- Desktop application support through Electron

## Technology Stack

- React
- JavaScript
- Vite
- [XYFlow](https://reactflow.dev/)
- Electron

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.

### Build for production

```bash
npm run build
```

The production files will be generated in the `dist` folder.
